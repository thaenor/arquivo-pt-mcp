📚 Arauto

Um MCP para o Arquivo.pt

GitHub   Estado: OK   Arquivo.pt

O que é isto?

O Arauto é uma ponte entre assistentes de IA e o Arquivo.pt — o arquivo web português que preserva páginas da internet desde 1996.

Com o Arauto, pode pedir ao seu assistente de IA para pesquisar notícias antigas, encontrar versões arquivadas de websites que já não existem, ou extrair texto de páginas históricas portuguesas.

Do que preciso?

Para usar este serviço, precisa de uma ferramenta de IA que suporte o protocolo MCP (Model Context Protocol). Eis algumas opções populares:

Claude (Anthropic) ChatGPT (OpenAI) Gemini (Google) Cursor Windsurf

Se já utiliza alguma destas ferramentas, pode configurar o Arauto para dar ao seu assistente acesso ao arquivo histórico português.

O que posso fazer?

Pesquisar
Pesquisa textual em páginas arquivadas
Pesquisar Imagens
Procura imagens no arquivo (1,8 mil milhões)
Listar Versões
Todas as capturas de um URL específico
Obter Página
Recupera uma página arquivada específica
Extrair Texto
Obtém o texto legível de uma página
Captura de Ecrã
Imagem PNG de como a página era

Como ligar

Adicione este servidor às configurações do seu cliente MCP. A configuração depende da ferramenta que utiliza:

Claude Desktop — edite o ficheiro de configuração:

{
  "mcpServers": {
    "arquivo-pt": {
      "url": "https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp"
    }
  }
}

Cursor / Windsurf — adicione às definições MCP:

{
  "mcpServers": {
    "arquivo-pt": {
      "url": "https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp"
    }
  }
}

Endereço do servidor:
https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp
