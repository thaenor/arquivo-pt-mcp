What is MCP?

Model Context Protocol (MCP) is an open standard that lets AI assistants like Claude, Cursor, and others connect to external data sources and tools. Think of it as a standardized plugin system for AI applications.

This server exposes the Arquivo.pt Portuguese Web Archive as a set of tools that AI assistants can use to search historical web content, retrieve archived pages, and extract information from the past.

Available Tools

search
Full-text search across the archive
image_search
Search 1.8B+ archived images
list_versions
Find all captures of a URL
get_snapshot
Fetch a specific archived page
extract_text
Get readable text from a page
get_screenshot
PNG render of archived page

How to Connect

Add this server to your MCP client configuration:

Claude Desktop — edit ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "arquivo-pt": {
      "url": "https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp"
    }
  }
}

Cursor / Windsurf — add to your MCP settings:

{
  "mcpServers": {
    "arquivo-pt": {
      "url": "https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp"
    }
  }
}

MCP Endpoint:

https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp

What Can You Do?

  • Search historical Portuguese web content dating back to 1996
