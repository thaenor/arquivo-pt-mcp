📚 Arauto

Pesquiste o arquivo web português com inteligência artificial

O que é?

O Arauto permite que assistentes de IA como o Claude, ChatGPT ou Gemini pesquisem no Arquivo.pt — o arquivo histórico da web portuguesa, com páginas desde 1996.

Pode pedir para encontrar notícias antigas, ver como era um site há 10 anos, ou extrair texto de páginas que já não existem.

Como usar

Não precisa de instalar nada!

Basta adicionar este endereço ao seu assistente de IA preferido.

https://decaf-squirrel-arquivo-pt-mcp.hf.space/mcp

Assistentes compatíveis

Claude (Anthropic) ChatGPT (OpenAI) Gemini (Google) Cursor Windsurf Cline

Configurar no Claude (versão web)

  1. Abra as Definições (canto superior direito)
  2. Vá a Connectors → Add custom connector
  3. Em Name escreva: arquivo-pt
  4. Em URL cole o endereço acima
  5. Guarde. Pronto! 🎉

Configurar no ChatGPT

  1. Abra as Settings (canto inferior esquerdo)
  2. Procure Connectors na secção de features
  3. Clique em Add connector
  4. Cole o endereço acima no campo MCP server URL
  5. Guarde. Pronto! 🎉

Experimente

Depois de configurado, pode pedir coisas como:

  • "Pesquisa notícias sobre o Euro 2004 em jornais portugueses"
  • "Mostra como era o site do Público em 2010"
  • "Encontra imagens antigas do Rossio em Lisboa"
  • "Quais as versões arquivadas do site do Banco de Portugal?"

Executar localmente

Se preferir privacidade total ou controlo sobre os dados, pode correr o Arauto no seu próprio computador. Consulte as instruções completas no GitHub.
